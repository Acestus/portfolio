.NET Storage Naming Lab

Check Azure storage account names with a C# file you can run locally with the .NET 10 SDK or later.

Download StorageNaming.cs

Try a valid name

dotnet run --file StorageNaming.cs -- stprojectdevscus001

Try a name with dashes

dotnet run --file StorageNaming.cs -- st-project-dev-scus-001

The validator checks for 3–24 lowercase ASCII letters or digits. Azure checks global name availability separately.
